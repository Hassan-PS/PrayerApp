Время намаза, которое не знает, кто вы.

Напоминания азана, компас киблы, виджет на главном экране и полный мединский мусхаф — без аккаунта, без рекламы и без аналитики. Как только задано местоположение, время рассчитывается на самом телефоне, и день работает при выключенной сети.

  • Без рекламы, трекеров и аккаунта
  • Работает без интернета
  • Бесплатно, открытый код

Версия 2.16.0 (261) • iOS, Android, macOS • AGPL-3.0-or-later • Исходный код на GitHub

Установка

Установить Mihrab

Одно и то же приложение во всех каналах, собранное из одного исходного кода. Сборка для F‑Droid идёт без сервисов Google Play.

На Mac: brew install --cask hassan-ps/tap/mihrab

Возможности

Поклонение целого дня — в одном приложении

Намаз

Обратный отсчёт до следующего намаза, напоминание азана для каждого времени, месячный обзор, компас киблы и виджеты на главном экране.

Коран

Полный мединский мусхаф в четырёх риваятах: чтение вслух, подсветка читаемого слова, тафсир, 14 переводов, закладки и план хатма.

Тилават

Слушание отдельной страницей: выберите чтеца — и чтение идёт сура за сурой с выключенным экраном, управляясь с экрана блокировки. Таймер сна, скорость и живая страница мусхафа, где подсвечивается читаемое слово.

Остальной день

Дуа из «Хисн аль-Муслим», тасбих, журнал поста и дневник намазов — и синхронизация между вашими устройствами без аккаунта.

Скриншоты

Как это выглядит

Светлая и тёмная тема, телефон и планшет. Мусхаф — это сама печатная мединская страница, а не её снимок. На скриншотах приложение по-английски; по-русски оно говорит так же.

Приватность

С телефона не уходит ничего, о чём вы не просили

Где вы находитесь пять раз в день — самое чувствительное, чего касается приложение для намаза. В этом коде нет ни аккаунта, ни аналитики, ни рекламной сети, ни отчётов о сбоях.

Остаётся на устройстве

Настройки, сохранённые места (в зашифрованном виде), дневник намазов и журнал поста. Уведомления планируются локально.

Уходит в сеть, когда вы этого хотите

Время из выбранного вами источника, поиск места и загрузка страниц мусхафа, переводов и чтений.

Отсутствует полностью

Ни рекламы, ни трекеров, ни аналитического SDK, ни сборщика сбоев, ни аккаунта. В сборке F‑Droid нет сервисов Google Play.

Частые вопросы

О чём спрашивают в первую очередь

Приложение бесплатное?

Да. Свободное ПО под лицензией AGPL‑3.0 и бесплатное: нет покупок внутри приложения, подписки и кнопки пожертвования.

Есть ли реклама или трекеры?

Ни того, ни другого. Нет рекламной сети, аналитического SDK, сборщика сбоев и аккаунта — этих библиотек в проекте попросту нет.

Работает ли без интернета?

Да. После указания местоположения время рассчитывается на устройстве, а уведомления планируются локально.

Какие устройства поддерживаются?

iPhone, iPad, Android и Mac. На Mac устанавливается через Homebrew.
