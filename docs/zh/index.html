不知道你是谁的礼拜时间。

宣礼提醒、朝向罗盘、主屏小组件，以及完整的麦地那版《古兰经》——无需账号，没有广告，没有分析统计。设定位置后，时间就在手机本地推算，因此断网也不影响一天的功课。

  • 无广告、无追踪、无账号
  • 断网也能用
  • 免费且开源

版本 2.16.0 (261) • iOS, Android, macOS • AGPL-3.0-or-later • GitHub 上的源码

安装

获取 Mihrab

各个渠道是同一个应用，由同一份源码构建。F‑Droid 版本不含 Google Play 服务。

在 Mac 上： brew install --cask hassan-ps/tap/mihrab

功能

一天的功课，集于一个应用

礼拜

距下次礼拜的倒计时、每个拜功的宣礼提醒、整月一览、朝向罗盘，以及主屏小组件。

《古兰经》

四种传述本的完整麦地那版，配诵读、逐词高亮、经注、14 种译文、书签，以及一份通读计划。

诵读

把聆听单独做成一页：选一位诵读者，熄屏后仍一章接一章地读下去，可从锁屏控制。睡眠定时、语速，以及一页实时的穆斯哈夫，正在诵读的词会被点亮。

一天的其余部分

《穆斯林的堡垒》祈祷词、赞念计数、封斋记录与礼拜日志——并可在自己的设备之间同步，无需任何账号。

应用截图

它长什么样

浅色与深色，手机与平板。穆斯哈夫就是印刷的麦地那版页面本身，而不是它的图片。截图里的应用是英文的；它同样说中文。

隐私

未经你要求，没有任何东西离开手机

一天五次你身在何处，是礼拜应用所触及的最敏感的信息。这份代码里没有账号、没有分析面板、没有广告网络，也没有崩溃上报。

留在设备上

设置、已保存的地点（加密存储）、你的礼拜日志与封斋记录。通知在本地排程。

你选择时才走网络

来自你所选来源的时间、地点搜索，以及经文页面、译文与诵读音频的下载。

根本不存在

没有广告、没有追踪器、没有分析 SDK、没有崩溃上报、没有账号。F‑Droid 版本不含 Google Play 服务。

常见问题

最先被问到的问题

这个应用免费吗？

免费。它是 AGPL‑3.0 许可下的自由软件，价格上也完全免费：没有内购、没有订阅、没有捐赠按钮。

有广告或追踪器吗？

都没有。没有广告网络、分析 SDK、崩溃上报或账号——这些库根本不在项目里。

离线能用吗？

能。设定位置后，时间在设备上推算，通知也在本地排程。

支持哪些设备？

iPhone、iPad、Android 和 Mac。Mac 上可用 Homebrew 安装。

许可

Mihrab 是 AGPL‑3.0‑or‑later 许可下的自由软件，源码在 GitHub 上。
